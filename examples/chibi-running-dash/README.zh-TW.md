# 範例：Q 版角色小跑步前衝攻擊

[English](README.md) | **繁體中文**

![Q 版角色小跑步前衝攻擊](final.gif)

側面的 Q 版女性騎士以小跑步接向前突刺，搭配方向性速度拖尾，再收招回到持劍姿勢。透明動畫為 **3.23 秒、112 格、768 × 768**。動作與特效由 Grok 生成，角色沿用先前原創圖片生成的設計。

## 製作流程

Codex 使用[加大留白的參考圖](reference.png)與[完整動作題詞](motion-prompt.txt)規劃動畫，將同一張圖提供為 `grok-imagine-video-1.5` 的首格與末格。此次製作以內建 OAuth client 的本次專用子類別加入 REST `last_frame` 欄位；它不是內建 CLI 選項。原始圖片工具未提供確切模型版本，因此不將此範例標示為 GPT-Image-2.5 產物。

[來源影片](source.mp4)以洋紅色鍵去背，tolerance 為 0.2、softness 為 0.18，縮至 256 像素寬後以最近鄰放大 3 倍。僅對半透明邊緣近似移除洋紅混色，保留 Alpha；使用[分段時長設定](timing.json)縮短停留並調整動作速度。GIF 使用共用色盤與專用透明索引，[APNG](final.apng)保留半透明。沒有本機疊加特效、扭曲姿勢、倒播或混圖銜接。


目前檔案另包含原生像素格的邊緣清理：僅在一像素寬輪廓帶抑制深色洋紅污染，Alpha 與輪廓內部 RGB 均未改動。來源中明亮的粉紫特效保留，未當作背景刪除。[邊緣前後對照](edge-comparison.png)（左：清理前；右：清理後）・[清理參數](cleanup.json)。這可減少紫邊，沒有使用模糊，也不代表去背已完全正確。

## 驗證與限制

112 格解碼後的 GIF 透明遮罩與來源門檻一致，**Alpha 錯誤為零**。APNG 解碼後的 RGBA 與輸出畫格完全一致，整段保留 357,327 個半透明像素樣本。沒有不透明前景像素碰到畫布邊界。這些檢查證明輸出完整性，不代表去背或動作已完全正確。

已檢查[動作分格圖](contact.jpg)與首尾姿勢，尚未完成正常播放速度下的目視驗收，因此不宣稱無縫與自然節奏已通過驗證。劍光比先前動作參考版收斂；此範例是已交付的修訂預覽，並非完整驗收的遊戲素材。
