# spec-12 — 把先前擱置的能力全部吸收（2026-11-05）

來源：使用者 2026-11-05「授權不用管 值得吸收的都吸收」。先前調查（research/open-source.md、competitors.md、rea-video）因授權只取概念或擱置的能力，
現在全部以「最強可得」為目標吸收；做法：寬鬆授權直接移植＋自動署名，其餘自行重寫同樣做法，或做成使用者自行安裝的選用引擎（不內建權重，預設仍可直接用）。
trunk-based，每個 S 一個切片；排在 spec-11 之後，可與 P3 導演整合並行。

## 規格
- S-140 **動態主體摳像（影片級）**：MatAnyone／RobustVideoMatting 等級的時間一致摳像作為選用引擎；同時自行實作「光流帶遮罩＋時間平滑」作為預設；
  頭髮、半透明、運動模糊邊緣的品質以錨點片比較（技術軸）。
- S-141 **鏡頭品質評分**：DOVER／Q-Align／MUSIQ 類分數作為選用引擎，進鏡頭卡的「技術」「美感（參考用，不定生死）」欄；預設仍用量測指標。
- S-142 **更強的音樂分析**：madmom 模型（重拍／小節）、All-In-One 式段落（verse／chorus／drop）作為選用引擎；Beat This! 仍為預設。
- S-143 **更強的深度**：Depth Anything V2 Base/Large、Video Depth Anything 大模型作為選用引擎（2.5D、運鏡、rack focus 品質提升）。
- S-144 **rea-video 的其餘能力**（自行實作）：每鏡判斷「實拍／AI 生成／3D／程式動效／螢幕錄影」並附證據；人聲／配樂／音效分離（Demucs 類選用引擎）；
  畫面文字（花字）抽取成 SRT／ASS＋樣式描述；反推 AI 鏡頭提示詞；把參考片的「哪些用拍、哪些用 AI、哪些寫程式」拆成成本與做法建議。
- S-145 **Remotion／Motion Canvas 的做法**：transition series、spring 物理、時間軸組合 API 的設計吸收進 fx_render 計畫語法（自行實作）。
- S-146 引擎管理：`vgs engines` 列出每個選用引擎（是否已裝、模型大小、CPU 耗時、品質差異實測）；`vgs engines install <name>` 由使用者觸發安裝；
  沒裝時自動退回預設，報告寫明用了哪個。
- S-147 每個新引擎：與預設做法在錨點素材上做技術軸比較，記錄「好多少、慢多少」，只有確實更好才在文件推薦。

## 驚豔時刻
丟一支別人的爆款片，導演不只拆出剪點與效果，還說得出「這三鏡是 AI 生成、這段是程式動效、配樂 128 BPM、花字是這種樣式」，
並用你的素材＋最強的摳像／深度／分析引擎，把同樣的節奏與質感做出來。
