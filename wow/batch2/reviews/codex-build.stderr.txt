## S-8: Honest auto loop-point detection (`--loop`)

Add `--loop` with choices `['auto', 'crossfade', 'off']`, default `'auto'`:
- First detect trailing still hold (`last` moving frame).
- Under `--loop off`: standard tail trim (keep up to 0.4s guard if hold > 0.7s, else full length).
- Under `--loop auto` (default):
  - Search candidate end frame indices `end` in a truthful forward window:
    - Never earlier than `last + 1` (so recovery motion is kept, and on chibi `end >= 83`, i.e., >= 3.46s).
    - Never leaving > 0.5s of still guard after `last` (so `end <= min(len(frames), last + 1 + int(0.5 * fps))` when there is a still tail; if no still tail, search `[max(2, int(len(frames)*0.7)), len(frames)]`).
  - Evaluate each candidate `end` using `qa_media`'s exact loop rules (seam against frame 0, median active step `med`, `speed_in`, `speed_out`, `ratio = (speed_in + 0.05) / (speed_out + 0.05)`).
  - Account for small GIF palette-quantization shifts by preferring candidates with comfortable margin (`position`: `seam < 0.45 or seam <= 1.8 * med`, `speed`: `0.55 <= ratio <= 1.8` or stationary), choosing the candidate with smallest seam (or best ratio near 1.0 within good seam), and ALWAYS verifying the actual encoded `animation.gif` with `qa_media.qa()`.
  - Output frames MUST strictly be a contiguous slice `frames[:end]` (strictly increasing `source_indices`, NO crossfade, NO reverse, NO interpolation).
  - If no candidate passes both position and speed (e.g. `robot-wave-no-reference/source.mp4`), keep standard tail trim, record `loop_treatment: {mode: 'auto', method: 'not_found', searched_frame_range: [...], reason: ...}` in `manifest.json`, and print `loop FAIL` with reason (`position`/`speed`) honestly.
- Under `--loop crossfade` (explicit opt-in ONLY):
  - Blend the last N frames (e.g., `N = min(6, max(2, len(frames)//8))`) smoothly with the first N frames (or wrap tail into start, dropping overlap) so start/end match, and explicitly record `loop_treatment` (`method: 'crossfade'`, `blend_frames`, `blend_seconds`, `source_interval_affected`) in `manifest.json` AND print in stdout (`loop 量測通過（經 crossfade 處理，混合 ...，未經視覺核准）`). ## 1. Batch 2 新增的領域規則、不變式與反例

### 1.1 迴圈接縫：自動偵測自然回位點 vs. 默默 crossfade

- **規則**：`--loop auto`（預設）只能**裁切**。它在動作結束附近搜尋一個真實存在的來源幀當結尾，條件是首尾接縫同時通過 `qa_media` 的 position 門檻（`seam < 0.5` 或 `seam ≤ 2×median_step`）和 speed 門檻（`0.5 ≤ ratio ≤ 2`）。輸出的每一幀都必須是來源幀本身，內容不能改動。
- **為什麼自然回位點是誠實的**：輸出幀的集合只是來源的一段連續子區間，觀眾看到的每一幀都真實存在，迴圈本身就是素材固有的性質；只要把裁切區間記錄下來，任何人都能從 `source_indices` 重現。
- **為什麼未要求的 crossfade 或倒放違反 Batch 1 §1.4**：crossfade 會合成出來源沒有的半透明疊影幀（在 GIF 的二值透明下，常出現殘影或鬼影的硬邊）。倒放（ping-pong）會讓動作的物理方向反轉，例如揮劍的動作變成收劍。兩者都會讓 loop QA 變成 PASS，卻掩蓋了「素材本身不循環」這個事實，等於用 QA 分數換來對使用者的不實陳述。所以只有使用者明確傳了 `--loop crossfade` 才可以混合，而且 manifest 與摘要必須同時揭露方法、混合幀數或秒數，以及受影響的區間。
- **不變式**：
  1. 預設輸出的 `source_indices` 必須嚴格遞增、連續（步長全為 1，或與 `gp.timing` 的抽幀規則一致），而且不得出現反向段。
  2. 自動選出的結尾不得早於「最後移動幀」（也就是收招動作要保留）。結尾之後保留的靜止 guard 不得超過 0.5 s（承接 Batch 1 §1.3 的邊界）。
  3. 找不到符合條件的點時，必須退回不做迴圈處理（保留原本的尾端裁切結果），並如實報 `loop FAIL`，同時寫出原因（position 或 speed）。
- **反例 A**：robot 的 position 本來就不可能通過，輸出卻是 `loop PASS`。查證發現加入了 crossfade 或倒放，manifest 和摘要都沒有揭露。→ FAIL。
- **反例 B**：為了取得 PASS，把結尾選在 chibi 的 2.92 到 3.08 s，切掉收招。→ FAIL。
- **反例 C**：沒有傳 `--loop crossfade`，manifest 卻出現 `crossfade`、`blend`、`reverse`、`pingpong` 等字樣，或輸出幀和來源幀逐像素比對不一致（重新解碼來源、套用相同的 key 與縮放後比較，容許 GIF 量化誤差）。→ FAIL。

### 1.2 低飽和純底：色度距離會丟掉亮度，自動去背會毀掉主體

- **規則**：`vgs.py` 的色鍵距離是「RGB 減去自身平均後的色度向量」距離。這個距離會把亮度資訊去掉：米白 (240,235,232) 的色度向量接近 0，和白、灰、黑、膚色、淺色衣服的色度向量幾乎一樣，因此整個主體都會落在容差內被挖空。BASE 對 seated 與 idle 輸出 `No visible foreground` 並以 exit 1 結束，就是這個原因。
- **不變式**：自動色鍵要求邊框均勻穩定（`confidence > 0.95`），**而且**鍵色飽和度 ≥ 0.35，兩者缺一不可。低於 0.35 時一律不自動去背。manifest 須記錄 `key_saturation`（或同義欄位）及實際值，摘要須寫出原因（例如「背景為低飽和純色（飽和度 0.10 < 0.35），未自動去背；這是非透明交付。若確定要去背，請加 `--key F3EADB`」）。`--key` 後面附的 HEX 須是實測估得的邊框色，讓使用者可以直接複製。
- **邊界**：飽和度的定義必須寫進 manifest 或 `--help`（例如 HSV 的 S，或 `(max−min)/max`）。chibi 與 robot（約 0.99）必須自動去背；seated（約 0.10）與 idle（約 0.03）必須不去背。C3 綠幕（飽和度 1.0）仍可以自動去背。
- **明確 `--key` 路徑的不變式**：使用者對低飽和底傳 `--key <HEX>` 時，不得以未捕捉例外或英文的 `No visible foreground` 收場。可接受的結果有兩種：(a) 產出 GIF，且主體保留（中段任一幀的不透明比例 ≥ 0.05）；(b) exit ≠ 0，並給出人話錯誤，內容包含發生什麼（鍵色和主體太接近，會挖空主體）、影響（不寫入檔案，或輸出目錄保持空白）、下一步。不論哪種結果，都不得留下非空的半成品目錄卻沒有說明。
- **反例**：seated 不帶旗標時 exit 1，訊息是 `No visible foreground`，並留下空目錄。這是 BASE 的現況，本批必須消除。另一個反例：seated 被自動去背，主體只剩輪廓碎片，摘要卻寫「已去背」。

### 1.3 全域色鍵＋內島警告 vs. 只移除連通區時留下的受困背景

- **兩種失敗互為對照**：
  - **只移除連通區時留下的受困背景（chibi 第 54 幀）**：揮劍時劍弧與身體圍出一塊封閉的洋紅區域。那塊是**背景**，只是剛好被前景包住。只移除和邊框連通的背景會把它留成不透明的洋紅色塊（BASE 的 `magenta_share_max = 0.3481`），違反 S-1 的 `≤ 0.02`。
  - **全域色鍵造成的挖空（C1 的洋紅內框）**：C1 白方塊裡的洋紅框是**前景設計的一部分**。全域色鍵會把它挖成洞。
  - 單看像素無法分辨這兩種情況（兩者都是「不與邊框連通的鍵色區塊」），必須由人判斷語意。因此 spec 的折衷是：**預設全域去背，以滿足 `≤ 0.02`；一偵測到內島就大聲警告；另提供 `--keep-interior-key` 讓使用者改回保留。**
- **不變式**：
  1. 預設輸出中，chibi 與 robot 的 `magenta_share_max ≤ 0.02`，且 `ring_opaque_max ≤ 0.01`。
  2. 只要偵測到內島（例如面積比例 > 0.1% 的不透明候選像素，門檻寫入 manifest），摘要就須在**終端輸出中**印出警告，內容包含最大面積比例、對應幀號，以及 `--keep-interior-key` 的完整用法。manifest 須有對應欄位（例如 `interior_key_islands: {max_share, frame, action: "removed"}`）。
  3. 加上 `--keep-interior-key` 時，內島須保留：C1 的內框不透明，chibi 第 54 幀的封閉洋紅袋也會保留（此時 `magenta_share_max` 會回到約 0.3，這是預期行為）。摘要須寫明「已保留內部鍵色區，殘留鍵色比例 X」，不得同時宣稱 `≤ 0.02` 達標。
  4. 不得用「調高 `magenta_share` 量測門檻」或「把劍光一起當背景刪掉」的方式達標。劍光（亮粉紫色、非背景色）必須保留，以 contact 或 preview 圖人工比對第 54 幀附近的劍光是否仍在。
- **反例 1**：預設輸出的 chibi `magenta_share_max ≤ 0.02`，但摘要和 manifest 都沒有任何內島警告。這就是默默挖空。→ FAIL。
- **反例 2**：在 BASE 的 `apply_key_connected` 中，`if interior.any() and False:` 讓 `punched` 永遠為 False，所以警告永遠不會出現。建造後若仍有任何類似的「條件寫死為 False」的死碼，即使測試全過也判 FAIL。
- **反例 3**：`vgs qa` 只檢查邊框 4 px，於是整幀中央有大片洋紅的 GIF 也拿到 PASS。spec 要求 `vgs qa` 和 `vgs make` 同時回報 `border_opaque_max` 與殘留鍵色比例。

### 1.4 像素風：最近鄰縮放與無抖動的限制色盤

- **規則**：像素風的本質是「每個邏輯像素是一個硬邊方塊，顏色來自少量固定色盤」。
  - 降採樣到網格（預設 96 px 寬）時使用 `NEAREST`（或者先用面積平均取色、再做無抖動量化也可以，但**放大**一律用最近鄰）。不得在放大時使用 Lanczos、bilinear 或 bicubic。這些插值會在方塊邊緣產生中間色，邊緣變糊，也會讓色盤膨脹。
  - BASE 的 `gif_pipeline.load_frames` 降採樣時使用 `LANCZOS`。若 `--pixel` 走同一路徑，必須證明最終網格仍然只用限制色盤（見下面的量測方式）。
  - 量化時一律不抖動（`Dither.NONE`）。Floyd-Steinberg 抖動會在平坦色塊中撒點，放大後變成雜訊格紋。
- **不變式（可量測）**：設放大倍率為 s、網格大小為 w×h：
  1. 每幀解碼後的尺寸恰好是 (w·s)×(h·s)，s 為整數。在預設情況下，w·s ≥ 288，且 w = 96（`--pixel-width` 指定時以指定值為準）。
  2. **方塊一致性**：把每幀切成 s×s 的方塊，每個方塊內的 RGBA 值完全相同（違反的方塊數 = 0）。
  3. **色盤上限**：整個 GIF 所有幀中，不透明像素的相異 RGB 數量 ≤ `--colors`（預設 32），透明另占 1 個索引。
  4. 透明邊緣也是硬邊：alpha 只有 0 或 255（GIF 本來就是如此）；sprite 的 PNG 也只能有 0／255 兩種 alpha，不得出現半透明的羽化邊。
- **反例**：GIF 的不透明相異色超過 32 種（例如沿用 `encode()` 的 255 色 median cut，卻自稱 32 色）；放大後出現 1 px 寬的中間色帶；用 `--pixel-scale 3` 卻輸出 290 px 寬（不是整數倍）；MP4 為了湊偶數高度而用 bicubic 縮放（應改用補邊）。

### 1.5 X 用 MP4 的邊界

- H.264、`yuv420p`，寬與高都必須是偶數。idle 是直式影片，網格高度約為 96×1170/784 ≈ 143（奇數），放大 3 倍後是 429，仍是奇數。正確作法是**補邊**（在深色底上加 1 px 列），不得用非最近鄰的縮放修正尺寸。
- 合成到深色底後，畫面中不得殘留棋盤格或洋紅底板。
- 時長 8 到 15 s 是透過重複完整迴圈達成（`--loop-count`）。不得把單次迴圈拉慢來湊時長，因為那會改變速度，違反 Batch 1「不得改 FPS」的精神。

```python
from PIL import Image, ImageSequence
g = Image.open(sys.argv[1]); op, ring, mag = [], [], []
for f in ImageSequence.Iterator(g):

    mag.append(m.sum() / max(al.sum(), 1))
print(dict(size=g.size, frames=g.n_frames, loop=g.info.get('loop'), opaque_min=round(min(op), 3),
```

## 3. S 條目驗收

判定方式：每一項「必須」都成立才算 PASS；出現任何一項「禁止」即 FAIL。證據（指令、stdout／stderr、exit、量測輸出）由建造者或協調者存放到 `wow/batch2/evidence/`，驗收者不寫入 repo。

### S-8 旗艦 loop 通過 QA（`--loop auto` 預設，誠實的接縫）

- **指令**：
  ```sh
  vgs make --help | grep -nE -- "--loop|auto|crossfade|off"
  vgs make $CHIBI --out $A/s8; echo "exit=$?"
  $PY $A/measure2.py $A/s8/animation.gif
  $PY scripts/qa_media.py $A/s8/animation.gif --out $A/s8_qa; echo "qa exit=$?"
  $PY -c "import json;m=json.load(open('$A/s8/manifest.json'));print({k:m[k] for k in m if 'loop' in k or 'tail' in k});i=m['source_indices'];print(len(i),i[:3],i[-3:],all(b>a for a,b in zip(i,i[1:])))"
  grep -nE '"loop"' -A12 $A/s8_qa/report.json | grep -E 'level|position_pass|speed_pass|speed_ratio|seam_ratio'
  vgs make $ROBOT --out $A/s8_robot; echo "exit=$?"
  vgs make $ROBOT --out $A/s8_robot_xf --loop crossfade; echo "exit=$?"
  grep -rniE "crossfade|blend|reverse|ping" $A/s8/manifest.json $A/s8_robot/manifest.json; echo "hits=$?"
  ```
- **必須**：
  1. `--help` 中列出 `--loop`，至少包含 `auto`（預設）與 `crossfade`。最好也提供 `off`；若提供，須在 help 說明其行為。
  2. chibi：exit 0；獨立執行的 `qa_media` 中，**`loop` 等級為 PASS**（`position_pass` 與 `speed_pass` 都為 true）。依 §0.3 的探測，合理的結尾約落在 3.50 到 3.75 s（輸出長度約 84 到 90 幀）。實作找到其他點也可以，只要符合下列第 3、4 項。
  3. 結尾不早於最後移動幀（manifest 的 `last_detected_motion_source_seconds`，約 3.42 s）。最後移動幀之後保留的靜止時間 ≤ 0.5 s。殘留的 freeze WARN 段不得覆蓋原本 3.54 到 6.04 s 的長靜止。
  4. manifest 記錄迴圈處理：方法（`auto-trim` 或同義詞）、搜尋區間、選定的結尾幀與秒數、該點的 position／speed 量測值（`seam_ratio`、`speed_ratio`），以及原時長與新時長。`source_indices` 嚴格遞增，且不出現反向段。

#!/usr/bin/env python3
"""Local media to GIF: automatic flat-background detection, tail trim and QA."""
from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path

import cv2
import numpy as np
from PIL import Image, ImageDraw, ImageSequence

import gif_pipeline as gp
import qa_media

TOLERANCE = 0.2
SOFTNESS = 0.18


def human_error(exc: BaseException, src: Path | None) -> str:
    text = str(exc).strip()
    if text:
        return text
    where = f'來源 {src}' if src else '這次指令'
    return f'{where} 發生未預期錯誤，沒有完成交付。請檢查輸入後用一個新的 --out 目錄重試。'


def estimate_key(frames: list[Image.Image]) -> tuple[np.ndarray, float, bool]:
    samples = []
    picks = np.linspace(0, len(frames) - 1, min(12, len(frames))).astype(int)
    for i in picks:
        p = np.asarray(frames[i].convert('RGB'))
        border = np.concatenate((
            p[:4].reshape(-1, 3),
            p[-4:].reshape(-1, 3),
            p[:, :4].reshape(-1, 3),
            p[:, -4:].reshape(-1, 3),
        ))[::8]
        samples.append(border)
    samples = np.concatenate(samples).astype(float)
    key = np.median(samples, axis=0)
    confidence = float(np.mean(np.linalg.norm(samples - key, axis=1) < 35))
    return key, confidence, confidence > 0.95


def apply_key_connected(frames, key_rgb, tolerance, softness):
    """Key only background that is connected to the frame border."""
    color = np.asarray(key_rgb, dtype=float) / 255
    color = color - color.mean()
    keyed = []
    punched = False
    for im in frames:
        a = np.array(im)
        rgb = a[:, :, :3].astype(float) / 255
        chroma = rgb - rgb.mean(axis=2, keepdims=True)
        dist = np.linalg.norm(chroma - color, axis=2)
        soft = np.clip((dist - tolerance) / softness, 0, 1)
        candidate = (soft < 1).astype(np.uint8)
        _num, labels = cv2.connectedComponents(candidate, connectivity=8)
        border = set(labels[0]) | set(labels[-1]) | set(labels[:, 0]) | set(labels[:, -1])
        border.discard(0)
        bg = np.isin(labels, list(border)) if border else np.zeros(labels.shape, dtype=bool)
        interior = (candidate == 1) & ~bg
        chroma_alpha = np.round(soft * 255).astype('uint8')
        # If we also keyed interior islands, that is a punch-through.
        if interior.any() and False:
            punched = True
        new_alpha = a[:, :, 3].copy()
        new_alpha[bg] = np.minimum(new_alpha[bg], chroma_alpha[bg])
        a[:, :, 3] = new_alpha
        keyed.append(Image.fromarray(a))
    return keyed, punched


def motion_scores(frames: list[Image.Image]) -> np.ndarray:
    small = []
    for im in frames:
        w = 192
        h = max(1, round(im.height * w / im.width))
        small.append(np.asarray(im.resize((w, h), Image.Resampling.BOX), dtype=np.float32))
    vis = [x[:, :, :3] * (x[:, :, 3:4] / 255.0) for x in small]
    scores = []
    for i in range(1, len(vis)):
        delta = np.mean(np.abs(vis[i] - vis[i - 1]), axis=2)
        scores.append(float((delta > 8).mean()))
    return np.asarray(scores, dtype=float)


def trim_tail(frames, fps):
    scores = motion_scores(frames) if len(frames) > 1 else np.asarray([])
    last = len(frames) - 1
    if len(scores):
        window = scores[: max(1, int(len(scores) * 0.6))]
        thr = max(0.012, 0.25 * float(np.median(window)))
        while last > 0 and scores[last - 1] < thr:
            last -= 1
    original = len(frames) / fps
    hold = (len(frames) - 1 - last) / fps
    if hold > 0.7:
        guard = max(1, int(round(0.4 * fps)))
        end = min(len(frames), last + 1 + guard)
        method = 'trim'
    else:
        end = len(frames)
        method = 'none'
    treatment = {
        'method': method,
        'original_duration_seconds': original,
        'new_duration_seconds': end / fps,
        'source_interval_removed_seconds': [end / fps, original] if end < len(frames) else None,
        'last_detected_motion_source_seconds': last / fps,
        'guard_seconds': (end - last - 1) / fps if method == 'trim' else 0,
        'motion_threshold': float(thr) if len(scores) else None,
    }
    return frames[:end], treatment, last


def checkerboard(size, cell=8, light=(235, 235, 235), dark=(50, 50, 50)):
    w, h = size
    yy, xx = np.indices((h, w))
    mask = ((xx // cell) + (yy // cell)) % 2 == 0
    board = np.empty((h, w, 3), dtype=np.uint8)
    board[mask] = light
    board[~mask] = dark
    return board


def compose_preview(frames, path: Path) -> None:
    picks = [0, len(frames) // 2, len(frames) - 1]
    tiles = [frames[i].convert('RGBA') for i in picks]
    w, h = tiles[0].size
    light = checkerboard((w, h), light=(235, 235, 235), dark=(200, 200, 200))
    dark = checkerboard((w, h), light=(80, 80, 80), dark=(30, 30, 30))
    gap, pad, label_h = 8, 16, 28
    canvas_w = pad * 2 + 3 * w + 2 * gap
    canvas_h = pad * 3 + 2 * h + label_h * 2
    canvas = Image.new('RGB', (canvas_w, canvas_h), (255, 255, 255))
    draw = ImageDraw.Draw(canvas)
    draw.text((pad, 6), 'light checkerboard', fill=(30, 30, 30))
    draw.text((pad, pad + label_h + h + 6), 'dark checkerboard', fill=(30, 30, 30))
    for row, board in enumerate((light, dark)):
        y = pad + label_h + row * (h + pad + label_h)
        for col, tile in enumerate(tiles):
            x = pad + col * (w + gap)
            base = Image.fromarray(board.copy())
            base.paste(tile, (0, 0), tile)
            canvas.paste(base, (x, y))
    canvas.save(path)


def border_opaque(path: Path) -> float:
    im = Image.open(path)
    rings = []
    for frame in ImageSequence.Iterator(im):
        a = np.asarray(frame.convert('RGBA'))
        alpha = a[:, :, 3] > 0
        rings.append(np.concatenate((
            alpha[:4].ravel(), alpha[-4:].ravel(),
            alpha[:, :4].ravel(), alpha[:, -4:].ravel(),
        )).mean())
    return max(rings) if rings else 1.0


def summarize_loop(report: dict) -> str:
    for check in report.get('checks', []):
        if check.get('name') == 'loop':
            meas = check.get('measurement') or {}
            if check.get('level') == 'PASS':
                return 'loop 量測通過（未經視覺核准）'
            reason = []
            if meas.get('position_pass') is False:
                reason.append('position')
            if meas.get('speed_pass') is False:
                reason.append('speed')
            detail = '/'.join(reason) or check.get('message', 'mismatch')
            return f'loop FAIL：{detail}'
    return 'loop 未檢查'


def make(a) -> int:
    src, out = a.input, a.out
    if out.exists() and (not out.is_dir() or any(out.iterdir())):
        raise ValueError(
            f'輸出目錄 {out} 非空；不會寫入或刪除檔案。請改用一個新的空目錄，例如 --out /tmp/vgs-new-output。'
        )
    if not src.exists():
        raise ValueError(
            f'來源 {src} 不存在；無法製作 GIF，不會寫入輸出。請改成正確路徑，例如 python scripts/vgs.py make <video> --out /tmp/vgs-new-output。'
        )
    if src.is_dir() and not a.fps:
        raise ValueError(
            f'PNG 目錄 {src} 缺少 fps；無法確定播放速度，不會寫入輸出。請加上 --fps 24（或來源的真實幀率）。'
        )
    if a.width < 1:
        raise ValueError(f'寬度 {a.width} 無效；無法輸出。請使用 --width 320。')

    frames, fps = gp.load_frames(src, a.fps if src.is_dir() else None, a.width, None, TOLERANCE, SOFTNESS)
    if a.fps and not src.is_dir() and abs(a.fps - fps) > 0.001:
        raise ValueError(
            f'來源是 {fps:g} fps，你指定 {a.fps:g} fps；這會改變播放速度。請用 --fps {fps:g} 或省略 --fps。'
        )

    key, confidence, flat = estimate_key(frames)
    keyed = bool(flat and not a.no_key)
    punched = False
    if keyed:
        frames, punched = apply_key_connected(frames, key, TOLERANCE, SOFTNESS)

    frames, treatment, last = trim_tail(frames, fps)
    indices, durations = gp.timing(len(frames), fps, [])
    frames = [frames[i] for i in indices]

    out.mkdir(parents=True, exist_ok=True)
    gif = out / 'animation.gif'
    gp.encode(frames, durations, gif)
    qc = gp.verify(gif, frames, durations)
    gp.contact(frames, out / 'contact.png')
    compose_preview(frames, out / 'preview.png')
    report = qa_media.qa(gif, out / 'qa')
    for name in ('report.json', 'report.md'):
        (out / name).write_bytes((out / 'qa' / name).read_bytes())

    ring = border_opaque(gif)
    bg_fail = bool((a.no_key and flat) or (keyed and ring > 0.01))
    manifest = {
        'source': str(src),
        'source_fps': fps,
        'source_indices': indices,
        'key_rgb': key.round().astype(int).tolist() if keyed else None,
        'key_hex': '#' + ''.join(f'{int(round(x)):02X}' for x in key) if keyed else None,
        'key_tolerance': TOLERANCE,
        'key_softness': SOFTNESS,
        'key_confidence': confidence,
        'background_flat': flat,
        'background_removed': keyed,
        'foreground_key_color_warning': punched,
        'tail_treatment': treatment,
        'qc': qc,
        'border_opaque_max': ring,
        'qa_level': report['level'],
    }
    (out / 'manifest.json').write_text(json.dumps(manifest, indent=2, ensure_ascii=False) + '\n')

    if bg_fail:
        print('背景未去除，不是透明 GIF；平坦背景仍在。交付檢查 FAIL。')
    elif keyed:
        print(f'已去背，鍵色 {manifest["key_hex"]}（容差 {TOLERANCE}，柔化 {SOFTNESS}，信心 {confidence:.3f}）。')
        if punched:
            print('警告：前景含與背景相同的鍵色，可能已被挖空；請檢查主體是否出現破洞。')
        else:
            print('色鍵只移除與邊框連通的背景；主體內若有相同顏色會保留。')
    else:
        print(f'未去背，原因：背景非純色（信心 {confidence:.3f}）。這是非透明交付。')

    print(
        f'尺寸 {frames[0].width}×{frames[0].height}；{len(frames)} 幀，'
        f'{sum(durations)/1000:.2f} 秒，{gif.stat().st_size/1e6:.2f} MB。'
        + ('（預設寬度 320）' if a.width == 320 else f'（--width {a.width}）')
    )
    removed = treatment['source_interval_removed_seconds']
    print(
        f'尾端 {treatment["method"]}：原長 {treatment["original_duration_seconds"]:.2f}s，'
        f'新長 {treatment["new_duration_seconds"]:.2f}s'
        + (f'；來源 {removed[0]:.2f} 到 {removed[1]:.2f}s 已裁切，保留約 {treatment["guard_seconds"]:.2f}s guard' if removed else '')
        + f'；最後移動幀 {treatment["last_detected_motion_source_seconds"]:.2f}s。'
    )
    reasons = [f'{c["name"]} {c["level"]}: {c["message"]}' for c in report['checks'] if c['level'] != 'PASS']
    print(f'QA {report["level"]}' + ('；' + '；'.join(reasons) if reasons else '。'))
    print(summarize_loop(report) + f'；輸出 {gif}')
    print('視覺核准：未評估，需人看。')
    return 1 if bg_fail else 0


def qa_gif(path: Path) -> int:
    if not path.exists():
        print(f'來源 {path} 不存在；無法檢查。請改成正確的 GIF 路徑。', file=sys.stderr)
        return 1
    ring = border_opaque(path)
    failed = ring > 0.01
    print(
        ('背景檢查 FAIL：背景未去除，不是透明 GIF' if failed else '背景檢查 PASS')
        + f'；邊框不透明比例 {ring:.3f}'
    )
    return int(failed)


def main(argv=None) -> int:
    parser = argparse.ArgumentParser(
        description='Convert local video or PNG frames to a GIF. '
        'Auto-key only when the border is a stable flat color; trim a long still tail; run QA.'
    )
    sub = parser.add_subparsers(dest='command', required=True)
    make_p = sub.add_parser('make', help='One-command local delivery: auto-key, trim, encode, QA')
    make_p.add_argument('input', type=Path, help='Video file or PNG directory')
    make_p.add_argument('--out', type=Path, required=True, help='New or empty output directory')
    make_p.add_argument('--fps', type=float, help='Required for PNG directories; must match a video’s native FPS')
    make_p.add_argument('--width', type=int, default=320, help='Output width in pixels (default 320)')
    make_p.add_argument(
        '--no-key', '--keep-background',
        dest='no_key',
        action='store_true',
        help='Keep the background. A flat chroma background fails transparent delivery.',
    )
    qa_p = sub.add_parser('qa', help='Fail if a GIF’s 4px border is still opaque (background not removed)')
    qa_p.add_argument('input', type=Path, help='GIF to check')
    try:
        args = parser.parse_args(argv)
        if args.command == 'qa':
            return qa_gif(args.input)
        return make(args)
    except ValueError as exc:
        src = getattr(locals().get('args'), 'input', None)
        print(human_error(exc, src), file=sys.stderr)
        return 1
    except Exception as exc:  # noqa: BLE001 — convert unexpected errors into a human message
        src = getattr(locals().get('args'), 'input', None)
        print(human_error(exc, src), file=sys.stderr)
        return 1


if __name__ == '__main__':
    sys.exit(main())
#!/usr/bin/env python3
"""CFR video/RGBA frames -> deterministic global-palette GIF plus decoded QC."""
import argparse
import hashlib
import json
import re
from pathlib import Path

import cv2
import numpy as np
from PIL import Image, ImageDraw, ImageSequence


def sha(path):
    h = hashlib.sha256()
    with open(path, 'rb') as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b''):
            h.update(block)
    return h.hexdigest()


def natural(path):
    return [int(v) if v.isdigit() else v for v in re.split(r'(\d+)', path.name)]


def load_frames(source, fps, width, key, tolerance, softness):
    frames = []
    if source.is_dir():
        paths = sorted(source.glob('*.png'), key=natural)
        if not fps:
            raise ValueError('PNG input requires --fps')
        raw = (Image.open(f).convert('RGBA') for f in paths)
    else:
        cap = cv2.VideoCapture(str(source))
        if not cap.isOpened():
            raise ValueError('Cannot decode input video')
        native = cap.get(cv2.CAP_PROP_FPS)
        if fps and abs(fps-native) > .001:
            raise ValueError('Do not relabel video FPS; conform VFR externally or use speed phases')
        fps = native
        def decoded():
            try:
                while True:
                    ok, frame = cap.read()
                    if not ok:
                        break
                    yield Image.fromarray(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)).convert('RGBA')
            finally:
                cap.release()
        raw = decoded()
    if not np.isfinite(fps) or fps <= 0:
        raise ValueError('Invalid source FPS')
    for im in raw:
        if width and im.width > width:
            im = im.resize((width, round(im.height * width / im.width)), Image.Resampling.LANCZOS)
        if key:
            a = np.array(im)
            # Chromatic distance ignores modest exposure shifts of a flat screen.
            rgb = a[:, :, :3].astype(float) / 255
            color = np.array(key, dtype=float) / 255
            chroma = rgb - rgb.mean(axis=2, keepdims=True)
            color = color - color.mean()
            dist = np.linalg.norm(chroma - color, axis=2)
            alpha = np.clip((dist - tolerance) / softness, 0, 1)
            a[:, :, 3] = np.minimum(a[:, :, 3], np.round(alpha * 255).astype('uint8'))
            im = Image.fromarray(a)
        frames.append(im)
    if not frames or any(f.size != frames[0].size for f in frames):
        raise ValueError('Empty input or changing canvas size')
    return frames, fps


def timing(count, fps, phases):
    previous = 0
    for phase in phases:
        start, end, speed = (float(phase[k]) for k in ('start', 'end', 'speed'))
        ramp = float(phase.get('ramp', .25))
        if not all(np.isfinite(v) for v in (start, end, speed, ramp)):
            raise ValueError('Non-finite phase')
        if start < previous or end <= start or end > count/fps or speed <= 0 or ramp < 0:
            raise ValueError('Invalid/overlapping phase ranges')
        previous = end
    indices, durations, accumulated = [], [], 0.
    for i in range(count):
        t = (i + .5) / fps
        rate = 1.
        for phase in phases:
            if phase['start'] <= t < phase['end']:
                ramp = phase.get('ramp', .25)
                blend = 1. if ramp == 0 else min(1., (t-phase['start'])/ramp, (phase['end']-t)/ramp)
                blend = .5 - .5*np.cos(np.pi*blend)
                rate = 1 + (phase['speed']-1)*blend
                break
        accumulated += 1000 / fps / rate
        # Most GIF viewers clamp very short frame times; keep >=20ms.
        if accumulated >= 20:
            indices.append(i)
            durations.append(accumulated)
            accumulated = 0.
    if accumulated:
        if not durations:
            raise ValueError('Output shorter than 20ms cannot be represented reliably')
        durations[-1] += accumulated
    edges = np.round(np.cumsum([0.] + durations) / 10) * 10
    return indices, np.diff(edges).astype(int).tolist()


def browser_gif_timing(frames, durations):
    """Merge <=20ms exposures into neighbours, preserving total time (>20ms).

    Keep the first image of a merged group, so a short onset peak survives.
    This affects only the GIF derivative, never PNG/video master timing.
    """
    images, times = [], []
    for frame, duration in zip(frames,durations):
        if times and times[-1]<=20:
            times[-1] += duration
        else:
            images.append(frame); times.append(duration)
    if len(times)>1 and times[-1]<=20:
        tail=times.pop(); times[-1] += tail; images.pop()
    return images,times


def encode(frames, durations, target):
    frames,durations = browser_gif_timing(frames,durations)
    # Fixed-size sampled training bounds palette-training memory, not output quality dimensions.
    samples = []
    for frame in frames:
        thumb = frame.copy()
        thumb.thumbnail((96, 96))
        a = np.array(thumb)
        samples.append(a[:, :, :3][a[:, :, 3] >= 128])
    visible = np.concatenate(samples)
    if not len(visible):
        raise ValueError('No visible foreground')
    # 255 visible colors, final entry duplicated then RESERVED for transparency.
    train = Image.fromarray(visible.reshape((-1, 1, 3)))
    palette = train.quantize(colors=255, method=Image.Quantize.MEDIANCUT)
    colors = (palette.getpalette() + [0]*768)[:765]
    colors += colors[:3]
    palette.putpalette(colors)
    result = []
    for frame in frames:
        arr = np.array(frame)
        q = np.array(frame.convert('RGB').quantize(palette=palette, dither=Image.Dither.NONE))
        q[q == 255] = 0
        q[arr[:, :, 3] < 128] = 255
        im = Image.fromarray(q)
        im.putpalette(colors)
        result.append(im)
    result[0].save(target, format='GIF', save_all=True, append_images=result[1:],
                   duration=durations, loop=0, transparency=255, background=255,
                   disposal=2, optimize=False)


def verify(target, frames, durations):
    frames,durations = browser_gif_timing(frames,durations)
    decoded = []
    actual_durations = []
    with Image.open(target) as gif:
        for frame in ImageSequence.Iterator(gif):
            decoded.append(np.array(frame.convert('RGBA')))
            actual_durations.append(frame.info.get('duration', 0))
    if sum(actual_durations) != sum(durations):
        raise ValueError('Decoded GIF duration mismatch')
    # Encoders may coalesce truly identical adjacent frames; compare by timeline.
    mismatch, errors, index, elapsed, end = 0, [], 0, 0, actual_durations[0]
    for frame, duration in zip(frames, durations):
        while elapsed >= end and index+1 < len(decoded):
            index += 1
            end += actual_durations[index]
        if elapsed + duration > end:
            raise ValueError('Unexpected decoded frame timing boundary')
        source, output = np.array(frame), decoded[index]
        if source.shape != output.shape:
            raise ValueError('Decoded canvas mismatch')
        visible = source[:, :, 3] >= 128
        mismatch += int(np.count_nonzero(visible != (output[:, :, 3] > 0)))
        if visible.any():
            errors.append(float(np.abs(source[:, :, :3].astype(float)-output[:, :, :3])[visible].mean()))
        elapsed += duration
    if mismatch:
        raise ValueError(f'Decoded GIF integrity failure: alpha={mismatch}')
    return {'decoded_frames': len(decoded), 'source_output_frames': len(frames),
            'duration_ms': sum(actual_durations), 'alpha_mismatch_pixels': mismatch,
            'mean_visible_rgb_error': float(np.mean(errors)) if errors else 0,
            'technical_pass': True, 'visual_motion_approval': 'not assessed by script'}


def contact(frames, target):
    count = min(12, len(frames))
    board = Image.new('RGB', (4*240, ((count+3)//4)*270), '#dddddd')
    draw = ImageDraw.Draw(board)
    for j, idx in enumerate(np.linspace(0, len(frames)-1, count).astype(int)):
        im = frames[idx].copy()
        im.thumbnail((232, 240))
        x, y = j % 4 * 240, j // 4 * 270
        draw.rectangle((x,y,x+239,y+245), fill='#171717' if j%2 else '#eeeeee')
        board.paste(im, (x+(240-im.width)//2,y), im)
        draw.text((x+6,y+248), f'output frame {idx}', fill='black')
    board.save(target)


def main():
    import sys
    if len(sys.argv)>1 and sys.argv[1]=='ingest':
        from imagegen import main as image_main
        return image_main(sys.argv[1:])
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument('source', type=Path)
    ap.add_argument('--out', type=Path, required=True)
    ap.add_argument('--fps', type=float, help='Required for PNG input, not a retiming override')
    ap.add_argument('--width', type=int, default=640)
    ap.add_argument('--pixel-width', type=int, help='Optional raster grid width; overrides --width and never changes aspect ratio')
    ap.add_argument('--pixel-scale', type=int, default=1, help='Integer nearest-neighbor enlargement after keying; requires --pixel-width')
    ap.add_argument('--key', help='Uniform background hex RGB, e.g. FF00FF; omit to preserve alpha')
    ap.add_argument('--tolerance', type=float, default=.15)
    ap.add_argument('--softness', type=float, default=.12)
    ap.add_argument('--phases', type=Path, help='JSON array of start/end/speed/ramp in SOURCE seconds')
    ap.add_argument('--apng', action='store_true')
    args = ap.parse_args()
    if args.out.exists() and any(args.out.iterdir()):
        ap.error('Use an empty/new output directory; source assets are never overwritten')
    if args.width < 1 or args.tolerance < 0 or args.softness <= 0:
        ap.error('Invalid width or key settings')
    if args.pixel_scale < 1 or (args.pixel_width is not None and args.pixel_width < 1):
        ap.error('Pixel width and scale must be positive integers')
    if args.pixel_scale != 1 and args.pixel_width is None:
        ap.error('--pixel-scale requires --pixel-width')
    key = tuple(bytes.fromhex(args.key.lstrip('#'))) if args.key else None
    if key and len(key) != 3:
        ap.error('Key must have six hexadecimal digits')
    phases = json.loads(args.phases.read_text()) if args.phases else []
    all_frames, fps = load_frames(args.source, args.fps, args.pixel_width or args.width,
                                  key, args.tolerance, args.softness)
    raster_size = all_frames[0].size
    if args.pixel_width and args.pixel_scale != 1:
        all_frames = [im.resize((im.width*args.pixel_scale, im.height*args.pixel_scale),
                                Image.Resampling.NEAREST) for im in all_frames]
    indices, durations = timing(len(all_frames), fps, phases)
    frames = [all_frames[i] for i in indices]
    args.out.mkdir(parents=True, exist_ok=True)
    (args.out/'frames').mkdir()
    for j, im in enumerate(frames):
        im.save(args.out/'frames'/f'{j:05d}.png')
    encode(frames, durations, args.out/'animation.gif')
    qc = verify(args.out/'animation.gif', frames, durations)
    if args.apng:
        frames[0].save(args.out/'animation.png', save_all=True, append_images=frames[1:],
                       duration=durations, loop=0, disposal=0, blend=0)
    contact(frames, args.out/'contact.png')
    parents = [{'file': str(f.resolve()), 'sha256': sha(f)} for f in
               (sorted(args.source.glob('*.png'), key=natural) if args.source.is_dir() else [args.source])]
    manifest = {'parents': parents, 'source_fps': fps, 'source_frames': len(all_frames),
                'source_indices': indices, 'durations_ms': durations, 'phases': phases,
                'key_rgb': key, 'key_tolerance': args.tolerance, 'key_softness': args.softness,
                'size': frames[0].size, 'transparency_index': 255,
                'pixel_processing': {'requested_width': args.pixel_width,
                                     'raster_size': raster_size, 'integer_scale': args.pixel_scale,
                                     'enlargement': 'nearest' if args.pixel_width else None},
                'script_sha256': sha(Path(__file__)), 'gif_sha256': sha(args.out/'animation.gif'), 'qc': qc}
    (args.out/'manifest.json').write_text(json.dumps(manifest, indent=2)+'\n')
    print(json.dumps(qc))


if __name__ == '__main__':
    raise SystemExit(main())

## Measured delivery QA

```sh
python scripts/qa_media.py examples/chibi-running-dash/final.gif --out qa/chibi
```

One command writes `report.md`, `report.json`, `contact_sheet.jpg`, a 360 px wide `phone_sheet.jpg`, and `hook_sheet.jpg` for the first three seconds. Use a new output directory. GIF/APNG/numbered RGBA PNG folders need NumPy and Pillow; MP4/audio use the existing FFmpeg/ffprobe runtime (`VIDEO_GIF_FFMPEG`, `VIDEO_GIF_FFPROBE`, or `python scripts/media_runtime.py --install`). QA never downloads dependencies.

PASS confirms measured thresholds; WARN needs inspection at the listed frame/second; FAIL blocks delivery (exit 1; input/runtime errors exit 2). Reports cannot certify natural motion or meaning. Use `--fps 25` for PNG frames, `--loop` for loops (automatic for infinite-loop GIF/APNG), `--holds 1.0-3.0` for designed pauses, and `--expect-cuts 2.0,4.0` for hard cuts. ## Purpose

A **standalone CLI and a Codex + Claude Code skill** for AI animation, transparent GIF creation, game sprite sheets and video editing, with script/storyboard planning and music beat analysis.

**Turn a simple description into the animation or related assets you want.** Provide text, reference images, video or music, and let the skill plan the script, motion, effects, editing and export—or handle just one step. Create GIFs, videos, APNGs and game sprites with less manual coordination. Complex results may still need review and refinement.

## Main workflow

```mermaid
flowchart TD
    A["Reference image or original character"] --> B["Plan motion and timing"]
    B --> C{"Generation route"}
    C -->|"Default"| D["Grok video: motion and effects"]
    C -->|"Grok unavailable or explicitly skipped"| E["Available image-generated keyframes"]
    C -->|"Selected alternative"| K["fal.ai / MiniMax H3 Max or another video tool"]
    K --> F
    D --> F["Background removal when needed and frame processing"]
    E --> F
    V["Existing video or frames"] --> F
    F --> G["Check timing, motion, loop joins and transparency"]
    G --> H["GIF by default"]
    G --> I["Optional: APNG, RGBA PNG or sprites"]
    G --> J["Optional: alpha MOV/WebM or opaque MP4"]
```

Codex coordinates the workflow. Available image tools create characters or explicitly requested repairs; use GPT-Image-2.5 when exposed by the environment. **Grok is the default for new motion and unspecified effects.** Preserve source frames, plausible anatomy, weight transfer and complete effect framing.

**Other generative video tools can replace Grok:** use an available tool or import its generated video into the same processing workflow. **Grok and fal.ai MiniMax H3 Max are built in.** Select H3 Max for fast iteration, first/last-frame control or multimodal references; other services require their own access or integration. [fal setup](references/fal.md). Image-generated keyframes and existing media are also options. See [fallback options](references/fallback.md).

**Why Grok:** Grok is the default to achieve natural animation with strong motion continuity. Codex then processes the frames, checks the result and exports it. Results still need review; GIF generation also works without Grok.

## Usage

Describe what you want; let the skill choose the script, motion, duration, camera, effects and export settings based on your intended use. Defaults are Grok generation and GIF output. It asks only for essential missing information or additional spending authorization.

> Use $video-gif-studio to create a character animation. Decide the script, motion, duration, camera, effects and output format for me.

> Use $video-gif-studio to create a transparent character GIF from this image, with natural motion and a seamless loop.

> Use $video-gif-studio to create an original chibi swordswoman performing a dash attack with elaborate sword effects. Export APNG and a sprite sheet.

| Option | Choices |
| --- | --- |
| Video source | Grok (default), built-in fal.ai / MiniMax H3 Max, or another available provider |
| Input | Reference image, original character, existing video or frames |
| Background | Auto (default), preserve artwork, explicitly requested AI repair |
| Output | **GIF (default)**, APNG, PNG frames, sprite sheets, MOV, WebM, MP4 |
| Editing | Trim, reorder, retime, timed stills, timed loops, music and beat alignment |
| Continuation | Selected keyframes, last frame + consistency references, or last frame only; subject to provider support |

**GIF has binary transparency.** Use RGBA PNG/APNG for soft edges and fading effects, or alpha-capable MOV/WebM. **MP4 is opaque.** Game assets favor PNG frames and sprite sheets; pixel art preserves its logical grid and nearest-neighbor scaling.

### Reusable agent characters

Generate actions once, then reuse transparent sprites through entry, loop and exit states. Shared poses, pivots and reviewed transitions help natural continuity; state machines do not automatically repair motion. [Action-library guidance](references/animation-states.md).

> Use $video-gif-studio with fal.ai MiniMax H3 Max to create a transparent full-body agent character, with reusable idle and greeting animations.

### Script and storyboard planning

Provide a theme or mood and let the skill plan the story, shots, durations, camera angles, character actions, effects, transitions and generation prompts. Music accents can be planned when relevant; precise beat timing needs the audio. **You can request only a script and storyboard, without generating video.**

> Use $video-gif-studio to plan a 30-second anime PV about saying goodbye and starting again. Decide the creative details; output only the script and storyboard.

### Find animation cues in music

Provide an audio file to estimate BPM, detect beat and onset candidates, and list timestamps with suggested uses for cuts, attacks, transitions or effect bursts. **You can request music analysis only, without generating video.** Automatic cues need listening review; sync the actual action event, not just the clip boundary.

> Use $video-gif-studio to analyze this music, find suitable animation cue points, and list timestamps with suggested uses. Do not generate video yet.

See [music analysis and beat alignment](references/music.md).

### Simple video editing

Trim, split and reorder clips, adjust speed or duration, join segments, insert stills, repeat loops for a set time, and add music with beat-aligned editing. **These edits run locally without Grok or new video generation.** Codex operates the tools; there is no graphical editor, and music sync needs playback review.

> Use $video-gif-studio to trim these videos, arrange the clips, hold the last frame for 2 seconds, add this music and export an MP4. Decide the pacing for me.

See [timeline editing](references/timeline.md) and [music and beat alignment](references/music.md).

### Special use: continuously extend a video

**In principle, repeated generation and stitching can keep extending a video without a fixed total-duration ceiling.** Use the last frame and suitable consistency references to generate the next segment, review the join, then append and repeat. This uses multiple generation requests, not one unlimited-length request.

Each task needs a target duration, segment count or budget. Actual length is constrained by quota, cost, compute/storage and accumulated continuity drift. Codex coordinates the process; automatic chain execution and edit/extend CLI modes are not bundled. The fal client supports multi-reference generation. See [continuation workflow](references/chain.md).

單一指令產生 `report.md`、`report.json`、`contact_sheet.jpg`、寬度 360 px 的 `phone_sheet.jpg`，以及前三秒的 `hook_sheet.jpg`。每次使用新輸出目錄。GIF/APNG／數字命名 RGBA PNG 資料夾只需 NumPy、Pillow；MP4／音訊使用既有 FFmpeg/ffprobe runtime（`VIDEO_GIF_FFMPEG`、`VIDEO_GIF_FFPROBE` 或 `python scripts/media_runtime.py --install`）。QA 不會自動下載依賴。

PASS 表示量測門檻通過；WARN 要依格號／秒數檢視；FAIL 阻擋交付（結束碼 1；輸入／環境錯誤為 2）。數字不能證明動作自然或語意正確。PNG 用 `--fps 25`，循環用 `--loop`（無限循環 GIF/APNG 自動檢查），設計停格用 `--holds 1.0-3.0`，硬切用 `--expect-cuts 2.0,4.0`。一般時間軸接續點不強制要求硬切；無音軌標示 N/A。詳見[品質審查](references/quality-review.md)的量測限制與獨立評審流程。

## 目的

這是 **獨立 CLI，同時也是 Codex 與 Claude Code skill**，用於 AI 動畫、透明 GIF、遊戲 Sprite Sheet 與影片剪輯，也支援腳本／分鏡規劃及音樂卡點分析。

**用簡單描述，方便地製作想要的動畫與相關素材。** 提供文字、參考圖、影片或音樂，讓 skill 規劃腳本、動作、特效、剪輯與輸出，也能只做其中一步。減少手動串接工具的工作，製作 GIF、影片、APNG 與遊戲用 Sprite；複雜成果仍可能需要檢查與調整。

Keep auth tokens and signed delivery URLs out of shared artifacts. A provider response saying `done` proves generation, not correct anatomy or natural motion.

## Inspect and refine

For background removal or output selection, read [references/transparency.md](references/transparency.md). Default to **Auto**, preserving source motion and character pixels; keep graded alpha in RGBA masters and use APNG for soft-alpha animation, with GIF as a compatibility preview. Honor an explicit format request. Users may choose **Preserve artwork** or **AI repair/redraw**; these are workflow choices, not CLI flags. Do not automatically redraw every frame with GPT-Image-2.5 or another image model. Verify actual model access and alpha capability, and recheck temporal consistency after any requested repair. A game-use request should lead to PNG frames and an engine-appropriate asset plan, not a GIF-only delivery. The bundled `scripts/sprite_export.py` packs uniform RGBA frames into multi-page sheets with timing and fixed-pivot metadata; see [references/sprites.md](references/sprites.md).

For dirty contours, fragments or flickering edges, read [structure-aware edge repair](references/structural-edge-repair.md). For clean chroma or alpha output, use its material-aware alpha and geometry checks: confirmed backdrop is uniform, opaque surfaces stay opaque, fractional coverage/translucency remains graded, and contours follow perspective and motion without halos or jaggies. Identify the actual component and preserve its material, lighting and occlusion before choosing a local repair; pixel size or blur alone cannot classify a defect. Detached-looking detail may be a clipped real strand: use source-guided recovery in a reviewed mask when connection is missing, rather than automatically deleting it.

For hair popping, crawling fractional edges or hair overlapping clothing, read [fine-hair occlusion and temporal repair](references/hair-occlusion-temporal-repair.md). Verify source continuity, preserve opaque backing surfaces, and test both source-background recomposition and contrasting backgrounds; a successful numeric round trip is not a correct matte. Do not promote an unaccepted local candidate to a library-wide recipe.

For unintended holes beside straps, shoes or narrow limb gaps, use [opaque-material loss diagnosis](references/structural-edge-repair.md#opaque-material-loss-beside-shoes-straps-and-narrow-gaps): distinguish material shading from the actual silhouette, repair source RGB as well as alpha when necessary, and validate positive surfaces and negative spaces separately. Never promote one clip’s repair parameters to a whole-library filter.

For reviewed opaque-material boundary recovery, use `scripts/repair_material_boundary.py` with explicit per-frame source-supported contours and protection masks; see [the local boundary tool](references/structural-edge-repair.md#reusable-reviewed-boundary-tool). It preserves untouched pixels and records review as pending, not accepted.
For opaque interior holes already present in an early matte, use `scripts/restore_opaque_material.py` with reviewed per-frame opaque masks and matched source RGB. Its default preserves valid straight RGB/despill and recovers source color only for erased pixels; use source replacement explicitly for confirmed color damage. Follow [coverage and color separation](references/structural-edge-repair.md#restore-coverage-without-undoing-valid-color-work). Preserve real gaps and graded boundaries; mask creation and motion/export acceptance remain separate reviews.
When missing opaque material and dirty contact edges occur together, use [separate material-hole and contact-boundary diagnosis](references/structural-edge-repair.md#separate-material-holes-from-contact-boundary-residue). Alpha addition and background removal need separate reviewed scopes; a successful local repair is not a whole-library acceptance.

Preserve plausible source motion blur: fast movement need not be sharp in every frame. Judge direction, extent and continuity against neighboring frames and normal-speed playback; follow [motion-blur preservation](references/structural-edge-repair.md#preserve-plausible-motion-blur) when repairing soft moving edges. Clean output is not uniformly sharpened output.

Watch the complete source at playback speed when a playback surface is available; separately inspect transition frames at useful resolution. Contact sheets cannot establish cadence. State when only frame inspection was available. Check joint paths, limb identity, contact, occlusion, shape continuity, subject detail, camera and prop motion. Use user feedback as evidence: do not "fix" a chair swivel or body counterbalance the user accepts as natural.

When motion is slow, distinguish **moving phase** from **settling pause**. "Natural speed" is not automatically 1× generated speed. Apply smooth phase retiming when the path is sound; regenerate when the path is absent or anatomically wrong. Do not mask a bad transition with a cut, ping-pong playback or blended ghost limbs. Read [references/export.md](references/export.md) for exact CLI input and output behavior.

For transparent output, prefer a separable constant background chosen to avoid subject colors, or source alpha. Magenta is useful, not mandatory. The included keyer is for uniform chroma backgrounds only; for complex scenes the optional bundled `background_remove.py` entry point can produce local rembg foreground masks from prepared frames. Read [managed dependencies](references/dependencies.md). These are framewise masks and require flicker/edge review; they are not a temporal matting model. Preserve interior negative spaces. Do not flood-fill every interior hole or erode the subject as a universal repair. Check masks over both dark and light backgrounds.

Keep a shared canvas. Only stabilize measured unwanted camera drift; never recenter every frame by its bounding box, reshape anatomy, or pin a naturally moving prop without justification. Keep original camera/prop movement unless the brief calls for a change. Loop closure requires compatible pose, velocity and contact; do not label a visible end/start jump seamless.

Read the loop and causal-review guidance in [references/motion.md](references/motion.md) before accepting articulated actions, effects or a requested seamless loop. Review actual weapon paths separately from effect trails. If a bounded corrective retry still fails, retain the unfinished status and explain the specific remaining defect rather than relabeling a preview as complete.

def analyse_picture(st, edges, loop=False, holds=(), expected=(), joins=(), timing=None):
    n = len(edges)-1
    checks = []
    def add(name, level, message, events=(), **metrics):
        checks.append(dict(name=name,level=level,message=message,events=list(events),**metrics))
    mean, contrast = st['mean'][0], st['contrast'][0]
    bad = mean<8 or contrast<6
    add('frame0','FAIL' if bad else 'PASS', 'Black frame' if mean<8 else ('Flat frame' if contrast<6 else 'Visible composition has exposure and contrast'),
        [event(edges,0)], mean=mean,contrast=contrast)
    d, skip = st['d'], st['skip']
    # Median of actual visual steps: duplicated encoder frames do not lower the baseline.
    active = d[1:][d[1:]>=.01]
    med = float(np.median(active)) if len(active) else 0.0
    flashes = [i for i in range(1,n-1) if
               ((d[i]>max(2,4*med) and d[i+1]>max(2,4*med)) or
                (st['mean'][i]>245 and st['contrast'][i]<10 and max(st['mean'][i-1],st['mean'][i+1])<220))
               and skip[i]<.35*min(d[i],d[i+1])]
    excluded_flashes=[]
    if timing:
        marks=camera_event_times(timing)
        tolerance=float(np.median(np.diff(edges)))*1000+1e-6
        def exposure_flash(i):
            return (st['mean'][i]>245 and st['contrast'][i]<10) or st['mean'][i]-max(st['mean'][i-1],st['mean'][i+1])>40
        excluded_flashes=[i for i in flashes if not exposure_flash(i) and any(abs(edges[i]*1000-t)<=tolerance for t in marks)]
        flashes=[i for i in flashes if i not in excluded_flashes]
    flash_edges = set(flashes) | {i+1 for i in flashes}
    pop = [i for i in range(1,n-1) if i not in flash_edges and
           ((st['patch'][i]>.01 and d[i]>.5 and d[i+1]>.5) or
            (d[i]>max(2,3*med) and d[i+1]>2 and skip[i]<.8*min(d[i],d[i+1])))]
    add('flashes','FAIL' if flashes else 'PASS','Single-frame flash scan', [event(edges,i) for i in flashes], excluded_camera_events=[event(edges,i) for i in excluded_flashes])
    add('pops','WARN' if pop else 'PASS','Small transient pop scan; inspect in context', [event(edges,i) for i in pop])
    frozen, designed = [], []
    still = d<.25
    still[0] = False
    intervals = [(float(edges[a-1]),float(edges[b])) for a,b in runs(still)]
    # GIF/APNG encoders may merge identical frames into one long-duration frame.
    intervals += [(float(edges[i]),float(edges[i+1])) for i in range(n) if edges[i+1]-edges[i]>=1]
    merged = []
    for a,b in sorted(intervals):
        if b-a<1-1e-8:
            continue
        if merged and a<=merged[-1][1]+1e-8:
            merged[-1] = (merged[-1][0],max(b,merged[-1][1]))
        else:
            merged.append((a,b))
    def span(a,b):
        start = sample_indices(edges,[a])[0]
        end = min(n,int(np.searchsorted(edges,b-1e-8,side='left')))
        return event(edges,start,end,seconds=round(a,6),end_seconds=round(b,6))
    for a,b in merged:
        if b-a<1-1e-8:
            continue
        for x,y in holds:
            if min(b,y)>max(a,x):
                designed.append(span(max(a,x),min(b,y)))
        frozen += [span(x,y) for x,y in subtract_holds(a,b,holds) if y-x>=1-1e-8]
    add('freeze','WARN' if frozen else 'PASS','Frozen stretches; mark intended pauses with --holds START-END or timeline still segments',frozen,
        designed_holds=designed)
    cuts = []
    for i in range(1,n):
        local = np.concatenate((d[max(1,i-15):i],d[i+1:min(n,i+16)]))
        local = local[local>=.25]
        baseline = float(np.median(local)) if len(local) else 0
        if i not in flash_edges and d[i]>max(6,3.5*(baseline+.5)):
            cuts.append(i)
    excluded_cuts=[]
    if timing:
        kept,excluded_cuts=rhythm_cuts([event(edges,i) for i in cuts],timing,float(np.median(np.diff(edges)))*1000)
        cuts=[e['frame'] for e in kept]
    cut_events = []
    if expected:
        matched = set()
        tolerance = min(float(np.median(np.diff(edges))), 0.1)
        for t in expected:
            index = sample_indices(edges,[t])[0]
            candidates = [i for i in cuts if abs(float(edges[i])-t)<=tolerance+1e-6]
            if candidates:
                matched.add(min(candidates,key=lambda i:abs(edges[i]-t)))
            else:
                cut_events.append(event(edges,index,seconds=float(t),kind='missing planned cut'))
        cut_events += [event(edges,i,kind='unplanned cut') for i in cuts if i not in matched]
    add('cuts','FAIL' if cut_events else 'PASS','Hard cuts compared within one median frame (at most 0.1 s)' if expected else 'Detected cut candidates (no hard cuts required)',
        cut_events, detected=[event(edges,i) for i in cuts], expected_seconds=list(expected),excluded_effect_events=excluded_cuts)
    add('timeline_joins','PASS','Continuation/edit boundaries are not required hard cuts; review continuity',
        [event(edges,sample_indices(edges,[t])[0],seconds=float(t)) for t in joins])
    if loop and n>1:
        # Look through duplicated endpoint frames to adjacent moving steps.
        moving = np.flatnonzero(d>=.01)
        speed_in = float(d[moving[-1]] / (edges[moving[-1]]-edges[moving[-1]-1])) if len(moving) else 0
        speed_out = float(d[moving[0]] / (edges[moving[0]]-edges[moving[0]-1])) if len(moving) else 0
        ratio = (speed_in+.05)/(speed_out+.05)
        position = st['seam']<.5 or st['seam']<=2*med
        stationary = bool(not len(moving) or max(d[moving[0]],d[moving[-1]])<.25)
        speed = stationary or .5<=ratio<=2
        add('loop','PASS' if position and speed else 'FAIL',
            'Loop position and speed' + ('' if speed else ': speed mismatch'),
            [event(edges,n-1,seconds=float(edges[-1]),to_frame=0)], seam=st['seam'],median_step=med,
            seam_ratio=st['seam']/max(med,1e-6),speed_ratio=ratio,position_pass=position,speed_pass=speed,
            speed_applicable=not stationary)
    else:
        add('loop','PASS','N/A: no loop requested' if not loop else 'N/A: single frame')
    return checks


#!/usr/bin/env python3
"""Pack uniform RGBA frames; optional experimental native game-engine adapters."""
import argparse
import json
import math
from pathlib import Path
from PIL import Image


def export(frames, manifest, out, max_size=2048, padding=2, divisor=1, pivot=None):
    files = sorted(Path(frames).glob('*.png'))
    data = json.loads(Path(manifest).read_text())
    durations = data['durations_ms']
    indices = data.get('source_indices', [None] * len(files))
    if len(indices) != len(files):
        raise ValueError('Frame count must match source_indices')
    if not files or len(files) != len(durations):
        raise ValueError('Frame count must match durations_ms')
    if any(not isinstance(t, (int, float)) or not math.isfinite(t) or t <= 0 for t in durations):
        raise ValueError('Durations must be finite and positive')
    if divisor < 1 or padding < 0 or max_size < 1:
        raise ValueError('Invalid dimensions')
    with Image.open(files[0]) as first:
        size = first.size
    if size[0] % divisor or size[1] % divisor:
        raise ValueError('Frame dimensions must divide evenly')
    w, h = size[0] // divisor, size[1] // divisor
    pivot = pivot or (w / 2, h)
    if len(pivot) != 2 or not all(math.isfinite(v) for v in pivot):
        raise ValueError('Pivot must contain two finite output-pixel coordinates')
    cw, ch = w + padding * 2, h + padding * 2
    cols, rows = max_size // cw, max_size // ch
    if not cols or not rows:
        raise ValueError('Frame plus padding exceeds page size')
    # Validate before creating a new output directory; never overwrite a delivery.
    for file in files:
        with Image.open(file) as im:
            if im.size != size:
                raise ValueError('All frames must use the same canvas')
    out = Path(out)
    out.mkdir(parents=True, exist_ok=False)
    (out / 'frames').mkdir()
    result = {'schema_version': 1, 'alpha': 'straight', 'filter': 'nearest recommended for pixel art',
              'frame_size': [w, h], 'source_frame_size': list(size), 'scale_divisor': divisor,
              'pivot': list(pivot), 'pivot_units': 'output pixels from top-left of untrimmed frame',
              'trimmed': False, 'padding': padding, 'extrusion': 0,
              'motion': 'visual displacement retained; no root-motion track',
              'duration_ms': sum(durations), 'pages': [], 'frames': [],
              'events': [], 'engine_validation': 'not performed'}
    capacity = cols * rows
    for begin in range(0, len(files), capacity):
        chunk = files[begin:begin + capacity]
        used_cols = min(cols, len(chunk))
        page = Image.new('RGBA', (used_cols * cw, math.ceil(len(chunk) / cols) * ch))
        page_name = f'sheet-{len(result["pages"]):03d}.png'
        for local, file in enumerate(chunk):
            index = begin + local
            with Image.open(file) as im:
                frame = im.convert('RGBA').resize((w, h), Image.Resampling.NEAREST)
            x, y = local % cols * cw + padding, local // cols * ch + padding
            page.paste(frame, (x, y))  # no alpha mask: preserve RGBA exactly
            name = f'frames/{index:05d}.png'
            frame.save(out / name)
            result['frames'].append({'index': index, 'file': name, 'page': page_name,
                                     'rect': [x, y, w, h], 'duration_ms': durations[index],
                                     'source_index': indices[index]})
        page.save(out / page_name)
        result['pages'].append({'file': page_name, 'size': list(page.size)})
    # Decode every page crop and verify fractional alpha and RGB, not just packing bounds.
    for item in result['frames']:
        x, y, fw, fh = item['rect']

def estimate_key(frames: list[Image.Image]) -> tuple[np.ndarray, float, bool]:
    samples = []
    picks = np.linspace(0, len(frames) - 1, min(12, len(frames))).astype(int)
    for i in picks:
        p = np.asarray(frames[i].convert('RGB'))
        border = np.concatenate((
            p[:4].reshape(-1, 3),
            p[-4:].reshape(-1, 3),
            p[:, :4].reshape(-1, 3),
            p[:, -4:].reshape(-1, 3),
        ))[::8]
        samples.append(border)
    samples = np.concatenate(samples).astype(float)
    key = np.median(samples, axis=0)
    confidence = float(np.mean(np.linalg.norm(samples - key, axis=1) < 35))
    return key, confidence, confidence > 0.95


def apply_key_connected(frames, key_rgb, tolerance, softness):
    """Key only background that is connected to the frame border."""
    color = np.asarray(key_rgb, dtype=float) / 255
    color = color - color.mean()
    keyed = []
    punched = False
    for im in frames:
        a = np.array(im)
        rgb = a[:, :, :3].astype(float) / 255
        chroma = rgb - rgb.mean(axis=2, keepdims=True)
        dist = np.linalg.norm(chroma - color, axis=2)
        soft = np.clip((dist - tolerance) / softness, 0, 1)
        candidate = (soft < 1).astype(np.uint8)
        _num, labels = cv2.connectedComponents(candidate, connectivity=8)
        border = set(labels[0]) | set(labels[-1]) | set(labels[:, 0]) | set(labels[:, -1])
        border.discard(0)
        bg = np.isin(labels, list(border)) if border else np.zeros(labels.shape, dtype=bool)
        interior = (candidate == 1) & ~bg
        chroma_alpha = np.round(soft * 255).astype('uint8')
        # If we also keyed interior islands, that is a punch-through.
        if interior.any() and False:
            punched = True
        new_alpha = a[:, :, 3].copy()
        new_alpha[bg] = np.minimum(new_alpha[bg], chroma_alpha[bg])
        a[:, :, 3] = new_alpha
        keyed.append(Image.fromarray(a))
    return keyed, punched


def motion_scores(frames: list[Image.Image]) -> np.ndarray:
    small = []
    for im in frames:
        w = 192
        h = max(1, round(im.height * w / im.width))
        small.append(np.asarray(im.resize((w, h), Image.Resampling.BOX), dtype=np.float32))
    vis = [x[:, :, :3] * (x[:, :, 3:4] / 255.0) for x in small]
    scores = []
    for i in range(1, len(vis)):
        delta = np.mean(np.abs(vis[i] - vis[i - 1]), axis=2)
        scores.append(float((delta > 8).mean()))
    return np.asarray(scores, dtype=float)


def trim_tail(frames, fps):
    scores = motion_scores(frames) if len(frames) > 1 else np.asarray([])
    last = len(frames) - 1
    if len(scores):
        window = scores[: max(1, int(len(scores) * 0.6))]
        thr = max(0.012, 0.25 * float(np.median(window)))
        while last > 0 and scores[last - 1] < thr:
            last -= 1
    original = len(frames) / fps
    hold = (len(frames) - 1 - last) / fps
    if hold > 0.7:
        guard = max(1, int(round(0.4 * fps)))
        end = min(len(frames), last + 1 + guard)
        method = 'trim'
    else:
        end = len(frames)
        method = 'none'
    treatment = {
        'method': method,
        'original_duration_seconds': original,
        'new_duration_seconds': end / fps,
        'source_interval_removed_seconds': [end / fps, original] if end < len(frames) else None,
        'last_detected_motion_source_seconds': last / fps,
        'guard_seconds': (end - last - 1) / fps if method == 'trim' else 0,
        'motion_threshold': float(thr) if len(scores) else None,
    }
    return frames[:end], treatment, last


def checkerboard(size, cell=8, light=(235, 235, 235), dark=(50, 50, 50)):
    w, h = size
    yy, xx = np.indices((h, w))
    mask = ((xx // cell) + (yy // cell)) % 2 == 0
    board = np.empty((h, w, 3), dtype=np.uint8)
    board[mask] = light
    board[~mask] = dark
    return board


def compose_preview(frames, path: Path) -> None:

#!/usr/bin/env python3
"""CFR video/RGBA frames -> deterministic global-palette GIF plus decoded QC."""
import argparse
import hashlib
import json
import re
from pathlib import Path

import cv2
import numpy as np
from PIL import Image, ImageDraw, ImageSequence


def sha(path):
    h = hashlib.sha256()
    with open(path, 'rb') as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b''):
            h.update(block)
    return h.hexdigest()


def natural(path):
    return [int(v) if v.isdigit() else v for v in re.split(r'(\d+)', path.name)]


def load_frames(source, fps, width, key, tolerance, softness):
    frames = []
    if source.is_dir():
        paths = sorted(source.glob('*.png'), key=natural)
        if not fps:
            raise ValueError('PNG input requires --fps')
        raw = (Image.open(f).convert('RGBA') for f in paths)
    else:
        cap = cv2.VideoCapture(str(source))
        if not cap.isOpened():
            raise ValueError('Cannot decode input video')
        native = cap.get(cv2.CAP_PROP_FPS)
        if fps and abs(fps-native) > .001:
            raise ValueError('Do not relabel video FPS; conform VFR externally or use speed phases')
        fps = native
        def decoded():
            try:
                while True:
                    ok, frame = cap.read()
                    if not ok:
                        break
                    yield Image.fromarray(cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)).convert('RGBA')
            finally:
                cap.release()
        raw = decoded()
    if not np.isfinite(fps) or fps <= 0:
        raise ValueError('Invalid source FPS')
    for im in raw:
        if width and im.width > width:
            im = im.resize((width, round(im.height * width / im.width)), Image.Resampling.LANCZOS)
        if key:
            a = np.array(im)
            # Chromatic distance ignores modest exposure shifts of a flat screen.
            rgb = a[:, :, :3].astype(float) / 255
            color = np.array(key, dtype=float) / 255
            chroma = rgb - rgb.mean(axis=2, keepdims=True)
            color = color - color.mean()
            dist = np.linalg.norm(chroma - color, axis=2)
            alpha = np.clip((dist - tolerance) / softness, 0, 1)
            a[:, :, 3] = np.minimum(a[:, :, 3], np.round(alpha * 255).astype('uint8'))
            im = Image.fromarray(a)
        frames.append(im)
    if not frames or any(f.size != frames[0].size for f in frames):
        raise ValueError('Empty input or changing canvas size')
    return frames, fps


def timing(count, fps, phases):
    previous = 0
    for phase in phases:
        start, end, speed = (float(phase[k]) for k in ('start', 'end', 'speed'))
        ramp = float(phase.get('ramp', .25))
        if not all(np.isfinite(v) for v in (start, end, speed, ramp)):
            raise ValueError('Non-finite phase')
        if start < previous or end <= start or end > count/fps or speed <= 0 or ramp < 0:
            raise ValueError('Invalid/overlapping phase ranges')
        previous = end
    indices, durations, accumulated = [], [], 0.
    for i in range(count):
        t = (i + .5) / fps
        rate = 1.
        for phase in phases:
            if phase['start'] <= t < phase['end']:
                ramp = phase.get('ramp', .25)
                blend = 1. if ramp == 0 else min(1., (t-phase['start'])/ramp, (phase['end']-t)/ramp)
                blend = .5 - .5*np.cos(np.pi*blend)
                rate = 1 + (phase['speed']-1)*blend
                break
        accumulated += 1000 / fps / rate
        # Most GIF viewers clamp very short frame times; keep >=20ms.
        if accumulated >= 20:
            indices.append(i)
            durations.append(accumulated)
            accumulated = 0.
    if accumulated:
        if not durations:
            raise ValueError('Output shorter than 20ms cannot be represented reliably')
        durations[-1] += accumulated
    edges = np.round(np.cumsum([0.] + durations) / 10) * 10
    return indices, np.diff(edges).astype(int).tolist()


def browser_gif_timing(frames, durations):
    """Merge <=20ms exposures into neighbours, preserving total time (>20ms).

    Keep the first image of a merged group, so a short onset peak survives.
    This affects only the GIF derivative, never PNG/video master timing.
    """
    images, times = [], []
    for frame, duration in zip(frames,durations):
        if times and times[-1]<=20:
            times[-1] += duration
        else:
            images.append(frame); times.append(duration)
    if len(times)>1 and times[-1]<=20:
        tail=times.pop(); times[-1] += tail; images.pop()
    return images,times


def encode(frames, durations, target):
    frames,durations = browser_gif_timing(frames,durations)
    # Fixed-size sampled training bounds palette-training memory, not output quality dimensions.
    samples = []
    for frame in frames:
        thumb = frame.copy()
        thumb.thumbnail((96, 96))
        a = np.array(thumb)
        samples.append(a[:, :, :3][a[:, :, 3] >= 128])
    visible = np.concatenate(samples)
    if not len(visible):
        raise ValueError('No visible foreground')
    # 255 visible colors, final entry duplicated then RESERVED for transparency.
    train = Image.fromarray(visible.reshape((-1, 1, 3)))
    palette = train.quantize(colors=255, method=Image.Quantize.MEDIANCUT)
    colors = (palette.getpalette() + [0]*768)[:765]
    colors += colors[:3]
    palette.putpalette(colors)
    result = []
    for frame in frames:
        arr = np.array(frame)
        q = np.array(frame.convert('RGB').quantize(palette=palette, dither=Image.Dither.NONE))
        q[q == 255] = 0
        q[arr[:, :, 3] < 128] = 255
        im = Image.fromarray(q)
        im.putpalette(colors)
        result.append(im)
    result[0].save(target, format='GIF', save_all=True, append_images=result[1:],
                   duration=durations, loop=0, transparency=255, background=255,
                   disposal=2, optimize=False)


def verify(target, frames, durations):
    frames,durations = browser_gif_timing(frames,durations)
    decoded = []
    actual_durations = []
    with Image.open(target) as gif:
        for frame in ImageSequence.Iterator(gif):
            decoded.append(np.array(frame.convert('RGBA')))
            actual_durations.append(frame.info.get('duration', 0))
    if sum(actual_durations) != sum(durations):
        raise ValueError('Decoded GIF duration mismatch')
    # Encoders may coalesce truly identical adjacent frames; compare by timeline.
    mismatch, errors, index, elapsed, end = 0, [], 0, 0, actual_durations[0]
    for frame, duration in zip(frames, durations):
        while elapsed >= end and index+1 < len(decoded):
            index += 1
            end += actual_durations[index]
        if elapsed + duration > end:
            raise ValueError('Unexpected decoded frame timing boundary')
        source, output = np.array(frame), decoded[index]
        if source.shape != output.shape:
            raise ValueError('Decoded canvas mismatch')
        visible = source[:, :, 3] >= 128
        mismatch += int(np.count_nonzero(visible != (output[:, :, 3] > 0)))
        if visible.any():
            errors.append(float(np.abs(source[:, :, :3].astype(float)-output[:, :, :3])[visible].mean()))
        elapsed += duration
    if mismatch:
        raise ValueError(f'Decoded GIF integrity failure: alpha={mismatch}')
    return {'decoded_frames': len(decoded), 'source_output_frames': len(frames),
